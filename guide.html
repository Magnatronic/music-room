How to make a launch link

A launch link opens one of these apps already set up the way you want it — the right notes, the right sound, ready to play. Other software (a room control panel, a menu button, a desktop shortcut) can use that link to start the app directly.

This takes about five minutes. You do not need to know anything about code, and nothing here can break the apps — the worst case is you make a preset you don't like and delete it.

The short version

Set the app up on screen → ⭐ Presets ▸ 🔗 Copy launch link → paste it into your software. The setup is carried inside the link, so nothing is saved on the computer and there is nothing anyone can delete. The three steps below are the same thing, spelled out.

First: decide where this folder is going to live

A link includes the folder's location, so links stop working if the folder is later moved or renamed. Decide its permanent home before you hand any links over — somewhere short and stable like C:\Music Room, not the Desktop or a Downloads folder.

If it does get moved later, nothing is lost: open the app from the folder's new home and copy the link again — it is always built from wherever the app actually is. Your presets and settings are unaffected by a move.

Making the link

  1. Set the app up exactly as you want it

    Open the app and use the tabs down the left — Notes, Sound, Visuals — until it looks and sounds right. How many notes, which scale, the voice, the volume, the colours. (Some apps call the first tab Songs, Chords or Scenes instead, depending on what it does.)

    Play with it properly at this stage. Whatever is on screen at the end is what the link will reproduce, every single time.

  2. Copy the launch link

    Tap ⭐ Presets in the left-hand menu, then 🔗 Copy launch link.

    That's it — the link is on the clipboard, and also on screen so you can copy it by hand if you need to. It looks like this:

    file:///C:/Music Room/drums.html?s=voice:bell,volume:0.22&lock=1

    Everything you changed in step 1 is written into the link itself. Nothing has been saved on the computer, so there is nothing for anyone to delete, and nothing to copy to another machine.

  3. Paste it into the launching software

    Wherever that software keeps the address it should open, paste the link in. Test it by opening the link yourself first — it should bring up the app looking exactly as you left it, with the menu hidden and ready to play.

    The &lock=1 on the end is what hides the menu. Delete that bit if you want the app to open with its controls showing.

Changing a setup later

Set the app up the new way and copy a fresh link, then paste the new link into the launching software in place of the old one. The old link keeps working — it just opens the old setup.

Presets, and how they relate to this

The ⭐ Presets panel also lets a therapist save a setup under a name (💾 Save preset) and load it back with one tap later. That is for use in the room — it saves dialling a familiar setup in from scratch every session.

Presets and launch links are independent. A link never refers to a preset by name: it carries its own settings. So a therapist can rename, change or delete presets freely and no link you have handed over is affected.

To get a link for a preset, load it with one tap and then press 🔗 Copy launch link — the link is built from whatever is on screen, however it got there.

Locked, and how to get back out

Start locked hides the whole menu when the app opens, so the person using it can only play. Nothing can be changed by accident — which is usually what you want in a sensory room.

To get the menu back: press and hold the top-left corner of the screen for 3 seconds. That is the only way in, and it is the same in every app. The app reminds you on screen when it opens locked.

The lock stays on until someone unlocks it, even if the app is closed and reopened.

If something isn't right

The link opens the app, but not with my setup
Make sure you copied the whole link — they can be long, and a link cut short loses the settings from the point it was cut. Opening the link yourself is the quickest way to check: what you see is exactly what the launching software will get.
Can someone delete or change my setup?
No. The setup lives inside the link, held by the launching software — nothing on the room computer defines it. Anyone can change the app while they are using it, and anyone can delete any preset, and the next launch still starts from your link exactly as before.
The link is quite long
It lists everything you changed from the app's normal settings, so the more you changed, the longer it is — typically a line or two, and it does not matter to the software reading it.
I moved the Music Room folder and the links stopped working
The links include the folder's location, so they change when it moves. Open each app from the folder's new home and copy its link again — the link is always built from wherever the app actually is, so it corrects itself.
I want a link for an app but no particular setup
Open the app, press ↺ Reset all settings to defaults, then 🔗 Copy launch link — with nothing changed you get a short link like drums.html?lock=1, which opens the app normally, ready to play.
